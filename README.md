# Face API Descriptor

An HTTP service built with Express and `face-api.js` for detecting a single face from an image and generating a **128-element floating-point face descriptor**.

The descriptor is intended for face recognition workflows and systems that require a **128-dimensional face descriptor**, including integration requirements for **FRISTA BPJS Kesehatan**.

## Requirements

* **Node.js 24** — the version used and tested with this service
* Native dependencies required by `canvas` and `@tensorflow/tfjs-node`
* Model files in the `models/` directory

> Other Node.js versions have not been specifically tested.

## Installation

```bash
npm install
cp .sample.env .env
```

Configure `.env`:

```dotenv
API_TOKEN=replace-with-your-secret-token
PORT=3000
```

`PORT` is optional and defaults to `3000`.

Do not commit `.env` to the repository.

## Running

Start the service:

```bash
node app.js
```

The application loads all required models before starting the HTTP server.

## API

### `GET /api/health`

Returns the service and model loading status.

```json
{
  "success": true,
  "modelsLoaded": true
}
```

No authentication is required.

### `POST /api/face/descriptor`

Detects a single face and generates a **128-element floating-point descriptor**.

#### Request

Required:

* `X-API-Token` header
* `image` property in the JSON body

The image can be raw Base64 or a Data URL such as:

```text
data:image/jpeg;base64,...
```

Example:

```bash
IMAGE_BASE64="$(base64 -w 0 ./face.jpg)"

curl -X POST http://localhost:3000/api/face/descriptor \
  -H "Content-Type: application/json" \
  -H "X-API-Token: replace-with-your-secret-token" \
  -d "$(jq -n --arg image "$IMAGE_BASE64" '{image: $image}')"
```

The JSON request body is limited to **10 MB**.

#### Response

When a face is detected:

```json
{
  "success": true,
  "detected": true,
  "score": 0.99,
  "descriptor": [0.012345, -0.023456, 0.034567],
  "box": {
    "x": 120,
    "y": 80,
    "width": 200,
    "height": 200
  },
  "processTimeSeconds": 0.123
}
```

The `descriptor` in the example is abbreviated. The actual response contains exactly **128 floating-point values**.

`processTimeSeconds` is the processing time measured in seconds.

If no face is detected:

```json
{
  "success": true,
  "detected": false,
  "message": "No face detected",
  "processTimeSeconds": 0.087
}
```

A no-face result still returns HTTP `200`.

A missing or invalid API token returns HTTP `401`.

## Face Descriptor

The face recognition model generates a **128-dimensional floating-point representation of the detected face**.

The resulting array always contains exactly **128 elements**.

The processing flow is:

```text
Image
  ↓
Face Detection
  ↓
Face Landmark Detection
  ↓
Face Recognition
  ↓
128-element Face Descriptor
```

The service generates the descriptor only. It does **not** perform identity matching.

## HTTP Status Codes

| Status | Description                      |
| ------ | -------------------------------- |
| `200`  | Request processed successfully   |
| `400`  | `image` was not provided         |
| `401`  | API token is missing or invalid  |
| `503`  | Models are not ready             |
| `500`  | Error while processing the image |

## Models

Required models are stored in:

```text
models/
├── ssd_mobilenetv1_*
├── face_landmark_68_*
└── face_recognition_*
```

They provide:

* **SSD MobileNet V1** — face detection
* **Face Landmark 68** — facial landmarks
* **Face Recognition** — 128-dimensional face descriptor

## Production

The service can be managed with PM2:

```bash
pm2 start app.js --name face-api
pm2 save
```

Useful commands:

```bash
pm2 status
pm2 logs face-api
pm2 restart face-api
```

The service can be placed behind a reverse proxy such as Nginx or OpenLiteSpeed:

```text
Client
   │
   │ HTTPS
   ▼
Reverse Proxy
   │
   │ HTTP
   ▼
Face API :3000
```

For production, the Node.js service can remain on a private/internal port while the reverse proxy handles external HTTPS traffic.
